# Balaji Earthmovers — Heavy Earthmoving & Civil Engineering Web Platform

A web platform for **Balaji Earthmovers** (est. 1991, Mumbai). Designed with a **Vivid Safety Construction Orange & Pure Luminous White** aesthetic, scroll-pinned interactive storytelling, machinery catalog, project ledger, and live contact desk.

---

## ✨ Features

- **Sticky Scroll-Pinning Storytelling (The Craft)**: Smoothly locks and steps through 3 deep excavation phases (*01: Bedrock & Breaking*, *02: Reclamation & Infrastructure*, *03: Foundations & Haulage*) with synchronized real-time progress.
- **Vibrant Safety Construction Palette**: High-visibility blaze orange (`#FF5E14`), rich Caterpillar amber (`#F59E0B`), pure white surfaces, and deep engineering navy (`#0B1528`).
- **Heavy Machinery Fleet Catalog**: Interactive cards for Volvo, Tata Hitachi, Komatsu, and heavy hydraulic rock breakers with popup technical spec sheets.
- **Landmark Projects Showcase**: Tabbed filterable ledger covering completed and ongoing deep basement excavations across Western Mumbai (Northern Heights, Dahisar Metro, Borivali commercial towers).
- **Interactive Estimate / Project Desk**: Volume estimation form with automated calculation and live toast notification.
- **Live IST Operations Clock**: Real-time IST Mumbai operational time tracker.
- **Floating Call & Action Beacon**: Quick-dial call desk with pulsing radar beacon.

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v16 or higher)

### Run Locally
```bash
# Start static server
node server.js
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 🛠️ Tech Stack
- **Structure**: Vanilla HTML5 (Semantic, SEO optimized)
- **Styling**: Vanilla CSS3 (Custom design system, chamfered bevel cuts, glassmorphism, responsive grid)
- **Engine**: Vanilla JavaScript (ES6+, IntersectionObserver, scroll-pinning engine)
- **Typography**: Google Fonts (*Barlow*, *Plus Jakarta Sans*, *JetBrains Mono*)
